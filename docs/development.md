# 개발 가이드

## 구조

[Feature-Sliced Design 2.1](https://feature-sliced.design)을 따릅니다. 화면이 한 페이지뿐이라 한 곳에서만 쓰는 코드는 모두 `pages/universe` 슬라이스 안에 두고(pages-first), 여러 곳에서 쓰는 UI와 유틸만 `shared`에 둡니다. `pnpm lint:fsd`(Steiger)로 검사합니다.

| 위치                                                | 내용                                                                                 |
| --------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `src/app/`                                          | 진입점(`entry-client`는 hydrate, `entry-server`는 사전 렌더링), 전역 CSS 디자인 토큰 |
| `pages/universe/model/solar/`                       | 천체 목록, 케플러 궤도·IAU 자전축(ephemeris), 화면 배율, 태양 진화, 기후             |
| `pages/universe/model/hazards/`                     | 충돌·편향, 태양 폭풍, 별 폭발, 근접 통과, N체 적분, 유성우                           |
| `pages/universe/model/world/`                       | 시뮬레이션 엔진(순수 함수)·조작·미션·스냅숏·Solid 스토어                             |
| `pages/universe/model/{stars,galaxy,local,cosmic}/` | 이웃 별·은하 천체·국부 은하군·거대 구조 자료, 은하 충돌, ΛCDM                        |
| `pages/universe/lib/`                               | GLSL 셰이더, 은하·우주 거미줄 생성기                                                 |
| `pages/universe/ui/scene/`                          | three.js 엔진(카메라·조작·이름표·선택)과 규모별 장면                                 |
| `pages/universe/ui/`                                | 소개, 뷰포트, 규모 사다리, 목적지 띠, 우주 관리 패널, 현황·정보 카드                 |
| `shared/ui/`                                        | Button, Tabs, RangeField, SelectField, ChoiceGroup, StatusMessage, ToggleButton      |

화면은 빌드 때 `vite build --ssr`로 만든 서버 묶음이 HTML로 그려 두고(`scripts/prerender.mjs`), 브라우저에서 Solid가 이어받습니다(hydrate). three.js 묶음은 바로 받기 시작하지만, 장면 생성은 첫 화면이 그려지고 글꼴을 받은 뒤 유휴 시간에 하며, 셰이더는 `compileAsync`로 미리 컴파일합니다.

## 상태

시뮬레이션 상태(`WorldState`)는 불변 객체 하나이고, 프레임마다 엔진 함수(`tick`)로 새 상태를 만듭니다. 3D 장면은 매 프레임 최신 상태(`currentWorld()`)를 읽고, 패널·카드는 Solid 신호(`world()`)를 읽습니다. 시간이 흐르는 동안 신호는 0.2초마다만 갱신하고(`UI_INTERVAL_MS`), 사건이 기록되거나 멈추거나 사용자가 조작하면 바로 갱신합니다. 화면 글자를 초당 60번 다시 계산하지 않아 메인 스레드 부담이 크게 줄었습니다.

화면 상태(규모, 고른 대상, 카메라가 따라가는 대상, 보기 설정)는 `model/view.ts`에 따로 둡니다. 목록이 갱신 때마다 새 객체로 바뀌는 곳(다가오는 소행성 등)은 id로 그려 입력값과 메시지가 사라지지 않게 합니다.

엔진은 프레임마다 다음 사건 시각(완공, 충돌, 폭풍 도달, 근접 통과 시작, 태양 단계 변화, 미션 끝)까지 연속 과정을 적분하고 그 시각의 사건을 처리하기를 되풀이합니다. 긴 구간은 5천만 년마다 상태를 점검해 바다가 마르는 때 같은 이정표가 제때 기록됩니다. N체 근접 통과는 하루 단위로 적분하므로, 진행 도중 근접 통과가 시작되면 그 뒤로는 한 프레임 분량(1,200일)만 진행하고 멈춥니다(시간 건너뛰기도 그 시점에서 멈추고 알림).

공유 링크와 브라우저 저장은 시각·예산·구조물·바뀐 궤도·사라진 천체·지구와 기지 상태만 담습니다. 다가오는 소행성, 아직 닿지 않은 태양 폭풍, 근접 통과, 별 폭발 잔해, 미션처럼 진행 중인 사건이 있으면 저장·공유 버튼을 막고 이유를 알립니다.

## 렌더링

- 행성 셰이더 하나가 텍스처(없으면 3D 잡음 표면), 태양 쪽 조명, 지구 밤 불빛, 바다가 마른 모습, 얼음, 테라포밍, 용암 빛, 오로라, 크레이터·대기 흔적·기지 불빛을 처리합니다. 대기는 뒷면 구에 가장자리 빛, 구름은 알파 채널 텍스처입니다.
- 태양은 잡음 쌀알 무늬와 주연 감광, 흑체 색(따뜻하게 보정)과 빛 번짐. 블랙홀은 그림자·광자 고리·강착 원반을 그리는 빌보드입니다.
- 소행성대·카이퍼 벨트는 정점마다 궤도 요소를 넣고 정점 셰이더에서 케플러 방정식을 풉니다.
- 1년/초보다 빠르면 공전이 깜빡이지 않도록 행성 위치를 멈추고 태양의 변화만 진행합니다.
- 이름표는 DOM 요소를 매 프레임 투영 위치로 옮깁니다. 화면에서 크게 보이는 선택 천체는 이름을 가운데에 둡니다(Space Advisor 방식).

## 언어

- `shared/i18n`: 언어 신호(브라우저에 기억), `<html lang>` 동기화, 보간
- `ui/messages.ts`, `ui/panels/messages.ts`: 화면 문구를 `[한국어, 영어]` 쌍으로 적고 `t(키, 값)`으로 씀. 두 언어의 `{자리}`가 같은지 테스트로 검사
- 자료(천체·별·은하·구조)는 `both(한국어, 영어)`로 이름과 설명을 함께 둠. 사건 기록은 생길 때 두 언어 문장을 함께 만듦

## 접근성

- 3D 장면은 마우스 없이도 씁니다: 장면 영역에 초점을 두고 화살표·`+`/`-` 키, 같은 기능의 버튼, 목적지 띠(라디오), 목적지 바로 가기(선택 상자).
- 소개 화면이 떠 있는 동안 `main` 랜드마크는 남기고 그 안의 장면·패널과 모바일 내비게이션만 `inert`. 시작하면 우주 관리 패널로 초점을 옮깁니다(스크롤은 하지 않음).
- 탭은 APG 패턴(화살표·Home·End, roving tabindex), 결과는 `role="status"`, 미션 결과는 네이티브 `<dialog>`(`showModal`).
- 상태는 색과 글자(알림·주의·경보·완료, 거주 가능·불모지 등)로 함께 보여 주고, 사라진 천체는 목적지 띠에 숨김 글자로도 알립니다.
- 보이는 글자가 접근 이름에 그대로 들어가도록(KWCAG 6.5.3) 버튼 이름을 맞췄습니다.
- 자동 회전은 끌 수 있고, '동작 줄이기'가 켜져 있으면 처음부터 꺼지며 섬광·고리 회전·카메라 이동 애니메이션도 멈춥니다.
